\## DO



\- Use TypeScript everywhere.

\- Keep components small.

\- Reuse services.

\- Reuse stores.

\- Use feature modules.

\- Mobile-first UI.

\- Strict typing.

\- Consistent formatting.



\## DON'T



\- Duplicate code.

\- Hardcode values.

\- Ignore TypeScript errors.

\- Use inline SQL.

\- Create large components.

\- Bypass RLS.

\- Commit secrets.

\- Mix business logic with UI.



\## NOTES



\- Production-ready.

\- Scalable.

\- Secure.

\- Maintainable.

\- Testable.
